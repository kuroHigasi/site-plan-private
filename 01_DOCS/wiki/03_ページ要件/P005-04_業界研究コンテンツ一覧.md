# P005-04: 🔍 業界研究コンテンツ一覧 (/certifications/research/)

## 基本情報
- 主目的: 管理者が実施している業界研究コンテンツ（キーワード検証など）の一覧を表示する。
- 想定ユーザー: 採用担当者、協業相手、ポートフォリオ閲覧者。
- 想定導線: 資格・学習コンテンツトップから遷移する。


## 表示内容

| 要素名          | 詳細                                        | 備考              |
|--------------|-------------------------------------------|-----------------|
| カテゴリ絞り込み     | カテゴリで絞り込み可能（表示するカテゴリは動的に決定） | 存在しないカテゴリは表示しない |
| 研究コンテンツ一覧      | 業界研究コンテンツをカード表示して一覧とする             |                 |

### 研究コンテンツカード表示について
| 要素名    | 詳細                       | 備考                     |
|--------|--------------------------|------------------------|
| アイコン   | カテゴリを示すアイコンを表示           |                        |
| サムネイル  | コンテンツのサムネイル画像を表示        | `alt` はコンテンツ名；`loading="lazy"` を付与 |
| コンテンツ名 | コンテンツのタイトルを表示             |                        |
| テーマ    | コンテンツのテーマ・主題を表示          |                        |
| 説明     | コンテンツの簡潔な説明文を表示          | 任意項目（存在する場合のみ表示） |
| リンク    | コンテンツ詳細ページ（P005-04-01など）へのリンク | クリックで詳細ページへ遷移 |

## ルーティング・実装方式

本ページは管理画面から業界研究コンテンツを追加した際に再ビルド不要で公開できるよう、**静的 HTML + API 取得**で構成する。

| 項目 | 方針 |
|------|------|
| URL 形式 | `/certifications/research/`（固定 URL） |
| ページ生成 | `certifications/research/index.astro` を 1 ファイルだけ静的生成する |
| データ取得 | ブラウザで `GET /api/public/research-contents.php` を呼び出してコンテンツ一覧を取得し描画する |
| コンテンツ追加運用 | 管理画面でコンテンツを公開すれば、再ビルド・再デプロイなしで一覧に追加される |

## SEO・アクセシビリティ
- パンくず: `共通仕様.md` 2.4 の P005-04 定義に準拠する（`トップ / 資格・学習コンテンツ / 業界研究`）。
- アクセシビリティ: カテゴリ絞り込みに `aria-label` を付与し、スクリーンリーダー対応を確保する。
- サムネイル: `<img>` に `alt` を必須とし、`loading="lazy"` を付与する。
