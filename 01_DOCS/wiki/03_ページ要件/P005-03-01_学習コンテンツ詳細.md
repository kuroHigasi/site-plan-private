# P005-03-01: 📖 学習コンテンツ詳細 (/certifications/contents/content-1/)

## 基本情報
- 主目的: 特定の学習コンテンツの概要、テーマ、難易度、章立て一覧を表示し、各章の詳細ページへ導く。
- 想定ユーザー: ポートフォリオ閲覧者、学習内容に興味のあるユーザー。
- 想定導線:
  - 主: P005-03（学習コンテンツ一覧）のコンテンツカードから遷移する。
  - 副: SNS や外部サイトからの直接リンク。

## ルーティング・実装方式

本ページは管理画面からコンテンツを追加した際に再ビルド不要で公開できるよう、**単一の静的ページ + クライアントサイド取得**で構成する（P006-06-01 に準拠）。

| 項目 | 方針 |
|------|------|
| URL 形式 | `/certifications/contents/{content-id}/`（パスベースで content-id を指定） |
| ページ生成 | `certifications/contents/[contentId].astro` を 1 ファイルだけ静的生成する。`content-id` 別の `getStaticPaths` は使用しない |
| データ取得 | ブラウザで URL パスから `content-id` を取得し、`GET /api/public/learning-contents.php?id={content-id}` を呼び出して描画する |
| コンテンツ追加運用 | 管理画面でコンテンツを公開すれば、再ビルド・再デプロイなしで詳細ページが閲覧可能になる |
| content-id 不正・未指定 | API の `id` 制約に準拠して検証し、不正・未指定時はエラー表示 + 一覧へ戻る導線を出す |
| content-id 不存在・非公開 | API が `404` を返すため「コンテンツが見つかりません」を表示し、一覧へ戻る導線を出す |

## 識別情報（管理画面連携）

| 項目 | 詳細 | 備考 |
|------|------|------|
| id | コンテンツ一意識別子（例: `1`） | 詳細ページの URL に使用；パスから抽出 |
| slug | URL 用識別子（例: `python-basics`） | パスベース URL に使用 |
| title | コンテンツのタイトル | 一覧・詳細・パンくずで共通 |
| theme | テーマ・主題（例: プログラミング、デザイン） | バッジ表示に使用 |
| description | コンテンツの詳細説明 | 詳細ページに表示 |
| thumbnail_url | サムネイル画像 URL | 詳細ページに表示 |
| created_at | 作成日 | `YYYY年M月D日` 形式等で表示 |
| is_published | 公開 / 下書き | 下書き時は詳細ページも非表示 |
| chapters | 章の配列 | 章一覧表示に使用；各章は `id`, `title`, `order` を含む |

## 表示内容

| 要素名 | 詳細 | 備考 |
|--------|------|------|
| タイトル | ページ見出し（H1）として表示 | パンくず・OGP タイトルに使用 |
| サムネイル | コンテンツのサムネイル画像を表示 | `alt` は コンテンツ名；`loading="lazy"` を付与 |
| テーマバッジ | コンテンツのテーマをバッジで表示 | |
| 説明文 | コンテンツの詳細説明を表示 | |
| 作成日 | コンテンツの作成日を表示 | `created_at` 等 |
| 章一覧 | コンテンツの全章をリスト表示（クリックで P005-03-01-01 へ遷移） | 章は順序付きで表示；クリックで `{content-id}/{chapter-id}` へ遷移 |
| 一覧へ戻る | P005-03 へのリンクを表示 | `画面遷移図.md` 備考に準拠 |

## クライアントサイド処理フロー

```text
[ユーザー] -> (ページ閲覧)
  └─> [Astro(静的HTML)] 描画完了（Loading 状態を表示）
        └─> [クライアントJS] 発火
              ├─> 1. URL パスから content-id を取得・検証
              ├─> 2. GET /api/public/learning-contents.php?id={content-id} へリクエスト送信
              ├─> 3. レスポンス（JSON）からコンテンツデータ・章一覧を抽出
              ├─> 4. document.title, OGP メタ情報を更新
              └─> 5. 対象 DOM 要素にコンテンツ詳細および章リストを描画（Success 状態）
```

## SEO・アクセシビリティ

- OGP: コンテンツタイトル・説明抜粋・テーマ・サムネイル画像を設定する（`05_SEOとアクセシビリティ方針.md` 参照）。クライアントで `document.title` と `og:*` メタを更新する。
- canonical: 自ページ URL を canonical とする。
- パンくず: `共通仕様.md` 2.4 の P005-03-01 定義に準拠する（`トップ / 資格・学習コンテンツ / 学習コンテンツ / [コンテンツ名]`）。
- サムネイル: `<img>` に `alt` を必須とし、`loading="lazy"` を付与する。
