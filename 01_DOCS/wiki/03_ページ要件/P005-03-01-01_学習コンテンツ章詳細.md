# P005-03-01-01: 📄 学習コンテンツ章詳細 (/certifications/contents/content-1/chapter-1/)

## 基本情報
- 主目的: 学習コンテンツの個別章の内容を閲覧可能なページを提供し、前後の章へのナビゲーションを提供する。
- 想定ユーザー: 学習コンテンツの読者、ポートフォリオ閲覧者。
- 想定導線:
  - 主: P005-03-01（学習コンテンツ詳細）の章一覧から遷移する。
  - 副: 前後の章ナビゲーション、または SNS・外部直接リンク。

## ルーティング・実装方式

本ページは管理画面から章を追加・更新した際に再ビルド不要で公開できるよう、**単一の静的ページ + クライアントサイド取得**で構成する（P006-06-01-01 に準拠）。

| 項目 | 方針 |
|------|------|
| URL 形式 | `/certifications/contents/{content-id}/{chapter-id}/` |
| ページ生成 | `certifications/contents/[contentId]/[chapterId].astro` を 1 ファイルだけ静的生成する。`content-id` や `chapter-id` 別の `getStaticPaths` は使用しない |
| データ取得 | ブラウザで URL パスから `content-id` および `chapter-id` を取得し、API を呼び出して描画する：`GET /api/public/learning-contents.php?id={content-id}&chapter={chapter-id}` |
| Markdown / テキスト変換 | API レスポンスの `content`（Markdown またはプレーンテキスト）を HTML 変換・サニタイズ（DOMPurify）して描画する |
| 章追加運用 | 管理画面で章を公開すれば、再ビルド・再デプロイなしで章の詳細ページが閲覧可能になる |
| パラメータ不正・未指定 | `content-id` または `chapter-id` が不正・未指定な場合、エラー表示 + コンテンツ詳細へ戻る導線を出す |
| コンテンツ/章不存在・非公開 | API が `404` を返すため「章が見つかりません」を表示し、コンテンツ詳細へ戻る導線を出す |

## 識別情報（管理画面連携）

| 項目 | 詳細 | 備考 |
|------|------|------|
| content-id | 親コンテンツの一意識別子（例: `1`） | URL パスから抽出 |
| content_slug | 親コンテンツの URL 用識別子（例: `python-basics`） | パンくず・ヘッダー表示に使用 |
| content_title | 親コンテンツのタイトル | パンくず・ヘッダー表示に使用 |
| chapter-id | 章の一意識別子（例: `1`, `2`） | URL パスから抽出 |
| chapter_title | 章のタイトル（例: 「第1章 環境構築」） | H1 見出しとして表示；パンくず・OGP タイトルに使用 |
| chapter_number | 章の番号（例: `1`, `2`） | 表示に使用（`第1章` 等） |
| chapter_order | 章の順序値 | 前後章ナビゲーション構築に使用 |
| published_at | 公開日 | `YYYY年M月D日` 形式等で表示 |
| is_published | 公開 / 下書き | 下書き時は非表示 |
| content | 章の本文コンテンツ | Markdown またはプレーンテキスト形式；HTML 変換・サニタイズして描画 |
| pdf_url | PDF ドキュメント URL（任意） | 存在する場合、ページ内埋め込み表示機能を提供 |
| youtube_videos | YouTube 動画リスト（任意） | 各動画は `id`, `title`, `thumbnail_url`, `video_id` を含む |

## 表示内容

| 要素名 | 詳細 | 備考 |
|--------|------|------|
| コンテンツタイトルリンク | 親コンテンツ（P005-03-01）へのリンク | コンテンツ名を表示し、コンテンツ詳細へ遷移可能にする |
| 章の見出し | 章のタイトル（H1）として表示 | パンくず・OGP タイトルに使用 |
| 公開日 | 章の公開日を表示 | `published_at` 等 |
| 目次 | Markdown 本文から自動生成される目次を表示 | H2、H3 見出しから生成；目次内のリンククリックで該当セクションへジャンプ |
| 本文表示領域 | 章の本文コンテンツを表示 | Markdown/テキスト形式で保存され、HTML に変換・サニタイズして描画 |
| PDF表示エリア | PDF ドキュメントを埋め込み表示（`pdf_url` が存在する場合） | PDF.js または同等のライブラリを使用；ページ内で表示・確認可能；ダウンロード機能も別途提供可 |
| YouTube動画セクション | 関連する YouTube 動画をサムネイル付きで表示（`youtube_videos` が存在する場合） | 各動画：サムネイル画像 + タイトル；クリックで動画ページへ遷移（別タブ） |
| 前後章ナビゲーション | 「前の章」「次の章」へのリンクを表示（複数章が存在する場合） | 存在する場合のみ前後の `chapter-id` に基づくリンクを表示 |
| コンテンツ詳細へ戻る | P005-03-01（コンテンツ詳細）へのリンク | 章一覧へ戻る導線 |

## クライアントサイド処理フロー

```text
[ユーザー] -> (ページ閲覧)
  └─> [Astro(静的HTML)] 描画完了（Loading 状態を表示）
        └─> [クライアントJS] 発火
              ├─> 1. URL パスから content-id および chapter-id を取得・検証
              ├─> 2. GET /api/public/learning-contents.php?id={content-id}&chapter={chapter-id} へリクエスト送信
              ├─> 3. レスポンス（JSON）から章の本文データ・コンテンツ情報・前後章情報・PDF URL・YouTube 動画リストを抽出
              ├─> 4. content を HTML へ変換し、DOMPurify でサニタイズ
              ├─> 5. Markdown 本文から見出し（H2、H3）を抽出し、目次を自動生成
              ├─> 6. PDF URL が存在する場合、PDF.js で埋め込み表示用の準備を行う
              ├─> 7. YouTube 動画リストが存在する場合、各動画のサムネイルと遷移リンクを準備
              ├─> 8. document.title, OGP メタ情報を更新
              └─> 9. 対象 DOM 要素に本文・目次・PDF・YouTube 動画およびナビゲーションを描画（Success 状態）
```

### 画面上の状態（State）定義

| 状態 | 表示内容 | 遷移条件 |
|------|----------|----------|
| Loading | スケルトン UI またはスピナーを表示 | ページ描画完了〜API レスポンス受信まで |
| Success | 変換後の HTML（章本文・ナビゲーション等）を描画 | API が正常レスポンス（200）を返却 |
| Error | 「章の取得に失敗しました」等のフォールバック表示 + コンテンツ詳細へ戻る導線 | API エラー（404・500 等）、ネットワークエラー、パラメータ不正 |

## セキュリティ

### XSS（クロスサイトスクリプティング）対策

API から返却される章本文テキスト内に悪意ある HTML/JavaScript タグが注入されている場合、描画時に実行されるリスクがある。

| 対策箇所 | 対策内容 |
|----------|----------|
| 管理画面（PHP 側） | 投稿・編集時に入力バリデーションを行う |
| フロントエンド | HTML 変換後、`DOMPurify` を通過させてから DOM に描画する |

| 項目 | 詳細 |

## 目次生成機能の仕様

| 項目 | 詳細 |
|------|------|
| 生成タイミング | Markdown 本文の HTML 変換後に実行 |
| 対象見出し | H2（`##`）および H3（`###`）見出しから抽出 |
| 表示箇所 | 本文表示領域の直上に配置 |
| リンク機能 | 目次内の各リンククリックで、対応する見出しへのページ内ジャンプを実装 |
| 自動 ID 生成 | 見出しテキストから自動生成した `id` 属性を HTML に付与し、アンカーリンク対応 |
| 折り畳み機能 | 任意：目次の折り畳み/展開ボタンを提供（UX 向上） |
| アクセシビリティ | `<nav>` タグで囲み、`aria-label="Table of Contents"` を付与 |

## SEO・アクセシビリティ

- OGP: コンテンツタイトル + 章タイトル・冒頭抜粋を設定する（`05_SEOとアクセシビリティ方針.md` 参照）。クライアントで `document.title` と `og:*` メタを更新する。
- canonical: 自ページ URL を canonical とする。
- パンくず: `共通仕様.md` 2.4 の P005-03-01-01 定義に準拠する（`トップ / 資格・学習コンテンツ / 学習コンテンツ / [コンテンツ名] / [章名]`）。
- アクセシビリティ: 行間やコントラスト比、フォントサイズなど、長文読書に適した視認性を確保する。
- 目次: `<nav>` タグで囲み、`aria-label="Table of Contents"` を付与；スクリーンリーダー対応。
- PDF: `<iframe>` または `<embed>` タグで埋め込む場合、`title` 属性を設定；代替テキストを提供。
- YouTube: `<a>` タグの `title` 属性にビデオタイトルを設定；動画への直接遷移は別タブで開く（`target="_blank"`、`rel="noopener noreferrer"`）。
