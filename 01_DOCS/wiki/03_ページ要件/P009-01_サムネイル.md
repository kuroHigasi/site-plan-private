# P009-01: サムネイル (/design/thumbnails/)

## 基本情報
- 主目的: YouTubeやブログ記事、SNS投稿用に作成したサムネイル画像を展示する。
- 想定ユーザー: デザインのバリエーションや表現力を確認したいユーザー。
- 想定導線: デザイン（P009）から遷移する。

## 表示内容

| 要素名 | 詳細 | 備考 |
|--------|---------------------------------------|--------------------------------------------------|
| 画像一覧 | 制作したサムネイル画像をグリッド形式で表示する。 | クリックで拡大表示（モーダル等）ができることが望ましい。 |
| フィルタリング | 「YouTube」「ブログ」「イベント」などの用途別に絞り込みが可能。 | |

### 各サムネイル表示項目（拡大表示時等）
| 要素名 | 詳細 | 備考 |
|--------|------------------------------|----------------------------------------|
| 画像 | サムネイル画像本体。 | |
| タイトル | 制作物の名称やテーマ。 | |
| 制作年月 | 制作した年月を表示。 | |
| 使用ツール | 制作に使用したツール（例: Adobe Photoshop, Figma）。 | |
| 説明 | 制作の意図や工夫したポイント。 | |
