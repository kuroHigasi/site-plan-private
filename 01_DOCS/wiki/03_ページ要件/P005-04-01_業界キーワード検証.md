# P005-04-01: 🔎 業界キーワード検証 (/certifications/research/keyword/)

## 基本情報
- 主目的: 異なる業界間のキーワード・用語の検証・分析結果を詳細に表示する。
- 想定ユーザー: 採用担当者、協業相手、業界研究に関心を持つポートフォリオ閲覧者。
- 想定導線: 業界研究コンテンツ一覧（P005-04）から遷移する。

## ルーティング・実装方式

本ページは **静的 HTML + API 取得**で構成する。ユーザーが別リポジトリの管理画面で登録したキーワード・ベクトル埋め込み・類似度キャッシュを、ブラウザのJavaScript で動的に取得・描画。

| 項目 | 方針 |
|------|------|
| URL 形式 | `/certifications/research/keyword/`（固定 URL） |
| ページ生成 | `certifications/research/keyword/index.astro` を 1 ファイルだけ静的生成する |
| データ取得方式 | ブラウザで複数の公開 API を呼び出してデータ取得・描画 |
| API エンドポイント | `GET /api/public/industries.php`、`GET /api/public/industry-keywords.php`、`GET /api/public/keyword-similarity.php`、`GET /api/public/keyword-search.php` |
| キャッシュ戦略 | 業界一覧・キーワード一覧: 60秒キャッシュ；類似度キャッシュ: 300秒キャッシュ；ベクトル検索: リアルタイム計算 |
| ページ更新タイミング | 別リポジトリの管理画面でキーワード・ベクトル・類似度キャッシュを更新 → 再ビルド・再デプロイ**不要**（API キャッシュ TTL 後に自動反映） |

## インタラクティブ機能仕様

### 業界選択インタラクション
- 業界リストから 1 つ以上選択可能（デフォルト: 単一選択、クエリパラメータで複数選択モード切り替え可）
- 子業界を持つ業界は `>` アイコンで展開・折畳み可能
- 選択後、該当業界のキーワード一覧をテーブルに描画
- 複数業界選択時は、業界間の類似度スライダーを表示

### キーワード一覧表インタラクション
- **ソート**: `keyword`（キーワード名）、`display_order`（表示順）、`importance_level`（重要度）で並び替え可能
- **絞り込み**: `theme`（テーマ）、`importance_level`（重要度）で絞り込み
- **ページネーション**: 100件/ページ表示（`per_page` パラメータで変更可能）
- **詳細表示**: キーワードをクリック → モーダルウィンドウで定義・根拠・参考資料を表示
- **ベクトル検索**: 各キーワード行に「このキーワードと類似する他のキーワード」検索ボタンを配置（オプション）

### 類似度フィルタパネル
- 2業界選択時に自動表示
- スライダーで最小類似度を指定（0.0～1.0、0.1 刻み）
- 閾値以上の業界ペアのみ、業界間マッピング表を表示
- フィルタクリアボタンで 0.0 に戻す

### 業界間マッピング表
- 2業界選択 + 類似度フィルタ設定時に表示
- 3つのセクション:
  1. 共通キーワード（両業界で使用）：テーブル形式、両業界での重要度を並記
  2. 業界 A 固有キーワード：テーブル形式、A での重要度のみ
  3. 業界 B 固有キーワード：テーブル形式、B での重要度のみ
- 各セクションの件数をヘッダーに表示

### ベクトル検索入力フォーム
- テキストエリアにベクトル埋め込み（JSON 配列形式）を貼り付け
  ```
  [0.123, -0.456, ..., 0.789]
  ```
- 「検索」ボタンをクリック → API `/api/public/keyword-search.php` を呼び出し
- 最小類似度スライダー（デフォルト: 0.7）で結果をフィルタ
- 検索結果をテーブル形式で表示（キーワード、類似度スコア、属する業界）

## パフォーマンス・非機能要件

- **データロード**: ページ初期化時に 4 つの API（業界一覧、初期業界のキーワード、すべての類似度キャッシュペア、業界数・キーワード総数）を並列呼び出し。全データ取得まで 2 秒以内が目標。
- **検索応答**: キーワード検索・ベクトル比較は 1 秒以内に応答。
- **UI 反応性**: インタラクション（業界選択、ソート、絞り込み、スライダー）は即座に反映（キャッシュ済みデータの再描画）。
- **ネットワーク負荷**: API レスポンスサイズを最小化し、gzip 圧縮対応。
- **キャッシュ戦略**: ブラウザキャッシュ + HTTP キャッシュヘッダー（`Cache-Control: public, max-age=60` 等）で、3000キーワード取得時の通信量削減。

## SEO・アクセシビリティ

- **パンくず**: `共通仕様.md` 2.4 の P005-04-01 定義に準拠（`トップ / 資格・学習コンテンツ / 業界研究 / 業界キーワード検証`）。
- **見出し構造**: H1 はページタイトルのみ、以降は H2, H3 で階層を構成。
- **テーブルアクセシビリティ**: 
  - `<table>` に `role="table"` / `aria-label="キーワード一覧"`
  - `<th>` に `scope="col"` / `scope="row"`
  - ソート可能なヘッダーには `aria-sort` 属性
- **キーボード操作**: 
  - Tab キーで全インタラクティブ要素にアクセス可能
  - Spacebar / Enter キーでボタン・チェックボックス操作
  - 業界ツリーは矢印キーで展開・折畳み可能（オプション）
- **スクリーンリーダー対応**:
  - モーダル表示時に `aria-modal="true"` / `role="dialog"`
  - フォーカストラップ（モーダル内のタブ操作が外に出ない）
- **外部リンク**: `rel="noopener noreferrer"` を付与、新タブで開く際は明示（例: `[参考資料 ↗]`）。
- **色情報に依存しない**: テーマ別の色分け表示に加え、テキストラベル / アイコン / 記号も併用。
