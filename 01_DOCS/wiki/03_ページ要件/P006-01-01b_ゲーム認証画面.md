# P006-01-01b: 🔐 ゲーム認証画面 (/works/games/auth?slug=:slug)

## 基本情報
- 主目的: パスワード保護されているゲームへのアクセス前に、4桁のパスワードで認証を行う。
- 想定ユーザー: パスワードを知っているユーザー。
- 想定導線: P006-01（ゲーム一覧）のパスワード保護ゲームカードから遷移する。
- パラメータ: `slug` で対象ゲームを指定する。

## 表示内容

| 要素名      | 詳細                               | 備考                                    |
|----------|----------------------------------|---------------------------------------|
| タイトル     | 「パスワードを入力してください」などのメッセージを表示 | 対象ゲーム名は表示しない（セキュリティ上の理由） |
| パスワード入力フィールド | 4桁の数字を入力するフォーム                | `type="password"`（ドット表示）。数字のみ入力可能 |
| 入力フィールド内ヒント | 「4桁のパスワード」などのプレースホルダ表示   | 例: `placeholder="0000"` |
| 認証ボタン  | パスワードを送信して認証を実行するボタン       | 成功時は `/works/games/detail?slug={slug}` へリダイレクト |
| 戻るリンク  | ゲーム一覧へ戻るリンク                   | キャンセル時の導線 |

## 認証仕様

| 項目         | 詳細                                    | 備考                                      |
|------------|---------------------------------------|----------------------------------------|
| パスワード長 | 4桁の数字                                | 例: 1234                               |
| バリデーション | 入力値が4桁の数字であることを確認        | 数字以外が入力された場合はエラーメッセージ表示 |
| 認証ロジック | API: `POST /api/public/game-auth.php` | リクエストボディ: `{ slug, password }` |
| 認証成功時  | セッション / Cookie に認証情報を保存    | 一定時間（例: 30分）の有効期限を設定 |
| 認証失敗時  | エラーメッセージを表示                    | 「パスワードが正しくありません」 |
| 試行回数制限 | 連続5回失敗時は一時的にアクセスブロック   | 10分後に解除。ブルートフォース攻撃対策 |

## セキュリティ考慮事項

- [ ] HTTPS通信の強制（パスワード暗号化）
- [ ] パスワードのハッシュ化（MD5ではなくbcryptなど安全なアルゴリズム）
- [ ] CSRF トークンの実装
- [ ] レート制限（ブルートフォース対策）
- [ ] ログ記録（認証失敗の記録）

## UX考慮事項

- [ ] スマートフォン対応（数字キーボード自動表示）
- [ ] 入力値の視認性確保（ドット表示の適切さ）
- [ ] エラーメッセージの明確さ
- [ ] フォーカス管理（初期フォーカスを入力フィールドに設定）
