# P010-01: ブログ記事 (/blog/article?slug=sample-article-1)

## 基本情報
- 主目的: ブログ記事の詳細情報を提供し、情報発信やポートフォリオの補完を行う。
- 想定ユーザー: ポートフォリオ閲覧者、採用担当者、情報収集を行うユーザー。
- 想定導線: ブログ（P010）から遷移する。

## 表示内容

| 要素名        | 詳細                                  | 備考 |
|------------|-------------------------------------|----|
| カテゴリ・スキル表示 | カテゴリとスキルを表示。                        |    |
| タイトル       | ブログ記事のタイトルを表示。 |    |
| サムネイル | サムネイル画像を表示。 |    |
| 本文         | ブログ記事の本文を表示。 |    |
| 関連記事表示     | 関連するブログ記事のリンクを表示。 |    |

## 備考
- 親ページ: ブログ（P010）を参照。
- 参考: `01_DOCS/02_サイト構成/画面遷移図.md`、`01_DOCS/wiki/01_コンセプト定義/05_SEOとアクセシビリティ方針.md`
- 表記ルール: ツール名は正式名称で表示する。
- 更新運用: ページ要件更新時は関連する`02_OUTPUT`の最新スクリーンショットとの差分確認を行い、不整合があれば先に要件を修正する。
