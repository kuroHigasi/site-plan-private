# P006-06-01-01: 📜 小説エピソード (/works/novels/episode?slug=sample-novel-1&episode=1)

## 基本情報
- 主目的: 小説作品の個別エピソード（各話）または短編小説の本文を快適に読めるリーダー画面を提供する。
- 想定ユーザー: 作品の読者、ポートフォリオ閲覧者。
- 想定導線:
  - 主: P006-06-01（小説詳細）のエピソード一覧（長編）または「本文を読む」ボタン（短編）から遷移する。
  - 副: 前後のエピソードナビゲーションからの連続読み、または SNS・外部直接リンク。

## ルーティング・実装方式

本ページは管理画面からエピソードや短編本文を追加・更新した際に再ビルド不要で公開できるよう、ブログ記事詳細（P010-01）と同様に**単一の静的ページ + クライアントサイド取得**で構成する。

| 項目 | 方針 |
|------|------|
| URL 形式 | **長編小説（複数話）**: `/works/novels/episode?slug={novel_slug}&episode={episode_number}`<br>**短編小説（単話）**: `/works/novels/episode?slug={novel_slug}`（`episode` パラメータは不要） |
| ページ生成 | `works/novels/episode.astro` を 1 ファイルだけ静的生成する。`slug` や `episode` 別の `getStaticPaths` は使用しない |
| データ取得 | ブラウザで URL パラメータから `slug`（作品識別子）および `episode`（話数番号）を取得し、API を呼び出して描画する：<br>・短編（`episode` なし）: `GET /api/public/novel-episodes.php?slug={slug}`<br>・長編（`episode` あり）: `GET /api/public/novel-episodes.php?slug={slug}&episode={episode}` |
| Markdown / テキスト変換 | API レスポンスの `content`（Markdown またはプレーンテキスト）を HTML 変換・サニタイズ（DOMPurify）して描画する |
| スタイル補正 | 小説本文の可読性に配慮したタイポグラフィスタイル（行間、フォントサイズ、字下げ等）を適用する |
| エピソード追加運用 | 管理画面でエピソードを公開すれば、再ビルド・再デプロイなしでエピソードが閲覧可能になる |
| パラメータ不正・未指定 | `slug` 未指定または不正な場合、エラー表示 + 小説一覧/詳細へ戻る導線を出す。<br>長編小説で `episode` が未指定または不正な場合は第1話へフォールバックするか、エラー表示と目次への導線を提示する。 |
| 作品/エピソード不存在・非公開 | API が `404` を返すため「エピソードが見つかりません」を表示し、作品詳細へ戻る導線を出す |

## 識別情報（管理画面連携）

| 項目 | 詳細 | 備考 |
|------|------|------|
| slug | 小説作品 URL 用識別子（例: `sample-novel-1`） | 英小文字・数字・ハイフンのみ |
| novel_title | 所属する小説作品のタイトル | パンくず・ヘッダー表示に使用 |
| is_short_story | 短編小説フラグ（短編 / 長編） | 短編の場合は単話構成となり `episode` パラメータ不要 |
| episode_number | エピソード話数（例: `1`, `第1話`） | 長編の場合に指定・表示。短編の場合は省略可 |
| episode_title | エピソードタイトル | 長編時は「話数 + サブタイトル」、短編時は作品タイトルまたは短編タイトル |
| published_at | 公開日 | `YYYY年M月D日` 形式等で表示 |
| is_published | 公開 / 下書き | 下書き時は非表示 |

## 表示内容

| 要素名 | 詳細 | 備考 |
|--------|------|------|
| 作品タイトルリンク | 親作品（P006-06-01）へのリンク | 作品名を表示し、小説詳細へ遷移可能にする |
| エピソード見出し | **長編**: 話数 + エピソードタイトル（H1）として表示<br>**短編**: 作品タイトルまたは短編見出し（H1）として表示 | パンくず・OGP タイトルに使用 |
| 公開日 / 更新日 | エピソードの公開日・最終更新日を表示 | `published_at` 等 |
| 本文表示領域 | エピソード本文を表示 | ルビ（ふりがな）や傍点、改行・字下げに配慮したレイアウト |
| 読書補助設定 | フォントサイズ変更、背景色/テーマ切り替え（明/暗）、縦書き/横書き切り替え等の読書サポート機能（任意・推奨） | 読者体験向上のためのUI設定 |
| 前後エピソードナビゲーション | **長編のみ**: 「前の話」「次の話」へのリンクを表示<br>**短編**: 非表示 | 存在する場合のみ前後の `episode` に基づくリンクを表示 |
| 目次 / 作品詳細へ戻る | P006-06-01（小説詳細）へのリンク | 作品詳細・エピソード一覧へ戻る導線 |

## クライアントサイド処理フロー

```text
[ユーザー] -> (ページ閲覧)
  └─> [Astro(静的HTML)] 描画完了（Loading 状態を表示）
        └─> [クライアントJS] 発火
              ├─> 1. URLSearchParams から slug および episode を取得・検証
              ├─> 2. API へリクエスト送信
              │      ├─ 短編（episode なし）: GET /api/public/novel-episodes.php?slug={slug}
              │      └─ 長編（episode あり）: GET /api/public/novel-episodes.php?slug={slug}&episode={episode}
              ├─> 3. レスポンス（JSON）からエピソード本文データ・作品情報・前後エピソード情報を抽出
              ├─> 4. content を HTML へ変換し、DOMPurify でサニタイズ
              ├─> 5. document.title, OGP メタ情報を更新
              └─> 6. 対象 DOM 要素に本文およびナビゲーションを描画（Success 状態）
```

### 画面上の状態（State）定義

| 状態 | 表示内容 | 遷移条件 |
|------|----------|----------|
| Loading | スケルトン UI またはスピナーを表示 | ページ描画完了〜API レスポンス受信まで |
| Success | 変換後の HTML（エピソード本文・ナビゲーション等）を描画 | API が正常レスポンス（200）を返却 |
| Error | 「エピソードの取得に失敗しました」等のフォールバック表示 + 作品詳細へ戻る導線 | API エラー（404・500 等）、ネットワークエラー、パラメータ不正 |

## セキュリティ

### XSS（クロスサイトスクリプティング）対策

API から返却されるエピソード本文テキスト内に悪意ある HTML/JavaScript タグが注入されている場合、描画時に実行されるリスクがある。

| 対策箇所 | 対策内容 |
|----------|----------|
| 管理画面（PHP 側） | 投稿・編集時に入力バリデーションを行う |
| フロントエンド | HTML 変換後、`DOMPurify` を通過させてから DOM に描画する |

## SEO・アクセシビリティ

- OGP: 作品タイトル + エピソードタイトル（短編時は作品タイトル）・冒頭抜粋・作品画像を設定する（`05_SEOとアクセシビリティ方針.md` 参照）。クエリパラメータ構成のため、API レスポンス取得後にクライアントで `document.title` と `og:*` メタを更新する。
- canonical: クエリパラメータ付きの自ページ URL（長編は `?slug={slug}&episode={episode}`、短編は `?slug={slug}`）を canonical とする。
- パンくず: `共通仕様.md` 2.4 の P006-06-01-01 定義に準拠する（長編: `トップ / 作品一覧 / 小説 / [作品名] / [エピソード名]`、短編: `トップ / 作品一覧 / 小説 / [作品名] / 本文`）。
- アクセシビリティ: 行間やコントラスト比、フォントサイズなど、長文読書に適した視認性を確保する。
