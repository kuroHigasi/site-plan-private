# P006-01-01: 🎮 ゲーム詳細 (/works/games/detail?slug=sample-game-1)

## 基本情報
- 主目的: 特定のゲームのコンセプト、遊び方、使用技術、工夫した点などを詳細に伝え、実際にプレイできるようにする。
- 想定ユーザー: ポートフォリオ閲覧者、採用担当者、ゲームプレイヤー。
- 想定導線:
  - 主: P006-01（ゲーム一覧）のゲームカードから遷移する。
  - 副: SNSや外部サイトからの直接リンク。

## ルーティング・実装方式
本ページは動画詳細（P006-04-01）と同様、クエリパラメータを用いた単一ページ構成とする。

| 項目 | 方針 |
|------|------|
| URL 形式 | `/works/games/detail?slug={slug}` |
| ページ生成 | `works/games/detail.astro` を 1 ファイルだけ静的生成する。 |
| データ取得 | ブラウザで `slug` を取得し、`GET /api/public/games.php?slug={slug}` を呼び出して描画する。 |
| パスワード保護 | `is_password_protected = 1` の場合、`GET /api/public/game-auth.php?game_id={slug}` を呼び出して認証状態を確認し、未認証（`authenticated: false`）であれば `P006-01-01b` へリダイレクトする。 |

## 表示内容

| 要素名 | 詳細 | 備考 |
|--------|------|------|
| ゲーム名 | ページ見出し（H1）として表示 | OGP タイトルに使用 |
| カテゴリ | ゲームのカテゴリ（2D, 3D, ウェブ, その他）を表示 | |
| 制作年月 | ゲーム制作の年月を表示 | `created_at` を `YYYY年M月` 形式で表示 |
| 使用技術 | 使用したエンジンや言語のタグを表示 | |
| ゲームプレイエリア | ゲームを実際にプレイ、または紹介するメインエリア | 条件により表示内容が異なる（下記参照） |
| ゲーム概要 | ゲームの内容、遊び方、特徴などを記載 | |
| 開発の経緯 | なぜこのゲームを作ったか、工夫した点などを記載 | |
| 反省点・今後の展望 | 開発を通じて学んだことや、改善したい点を記載 | |
| 外部リンク | GitHubリポジトリや、外部公開サイト（itch.ioなど）へのリンク | 存在する場合のみ表示 |
| 一覧へ戻る | P006-01 へのリンク | |

## ゲームプレイエリアの表示要件

ゲームのカテゴリと使用技術に応じて、表示方法を切り替える。

| 条件 | 表示方式 | 詳細仕様                                                                                        |
|------|----------|---------------------------------------------------------------------------------------------|
| **カテゴリ：ウェブ**<br>**使用技術：Phaser3** | **iframe 表示** | `slug` から判別できるフォルダ内の `index.html` を `iframe` で表示する。<br>（例: `/games/game/{slug}/index.html`） |
| 上記以外（Unity WebGLなど） | 埋め込み or リンク | 各プラットフォームに応じた埋め込み、または外部サイトへの誘導。                                                             |

### iframe 表示の詳細
- **パス構成**: `slug` で指定した ID から判別できるフォルダに配置してある `index.html` を `src` に指定する。<br>例: `public/games/{slug}/index.html` に配置されている場合、ウェブ上からは `/games/{slug}/index.html` として参照する。
- **レスポンシブ対応**:
  - ゲームのキャンバスサイズ（例: 800x600）を維持しつつ、画面幅に合わせて `iframe` のサイズを調整する。
  - アスペクト比を維持するためのコンテナ（`aspect-ratio` 等を利用）内で表示することを推奨。
- **操作性**:
  - `iframe` 内をクリックすることでゲームにフォーカスを当て、キーボード操作（矢印キー等）がゲームに伝わるようにする。
  - ゲームプレイ中にページが意図せずスクロールしないよう、フォーカス時のスクロール抑制などの検討が必要。
- **フォールバック**: 何らかの理由で `iframe` が読み込めない場合、または JavaScript 無効環境では、ゲームのサムネイルと直接リンクを表示する。

## SEO・アクセシビリティ
- **OGP**: ゲーム名・概要・サムネイル画像を設定する（`05_SEOとアクセシビリティ方針.md` 参照）。
- **canonical**: `?slug=` 付きの自ページ URL を canonical とする。
- **アクセシビリティ**: 
  - `iframe` には適切な `title` 属性（例: `{ゲーム名}のゲームプレイ画面`）を付与する。
  - キーボードのみでの操作（一覧へ戻るリンクへの移動など）が可能であることを確認する。
