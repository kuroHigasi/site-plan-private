# P009: デザイン (/design/)

## 基本情報
- 主目的: デザイン関連の成果物（サムネイル、アイコンなど）をカテゴリ別に紹介し、制作物の質とスタイルを伝える。
- 想定ユーザー: ポートフォリオ閲覧者、採用担当者、デザイン依頼を検討しているユーザー。
- 想定導線: トップページ・作品一覧から遷移する。

## 表示内容

| 要素名 | 詳細 | 備考 |
|--------|--------------------------------------------------------|--------------------------------------------------|
| イントロダクション | デザイン活動の概要や、制作におけるこだわり（コンセプト、使用ツール等）を簡潔に説明。 | |
| カテゴリ一覧 | 「サムネイル」「アイコン」などのデザインカテゴリをカード形式で表示し、各詳細ページへ誘導する。 | P009-01、P009-02 へのリンク。 |

### カテゴリカード表示について
| 要素名 | 詳細 | 備考 |
|--------|-----------------------------------------------|---------------|
| カバー画像 | 各カテゴリを象徴する代表的な制作物の画像を表示。 | |
| カテゴリ名 | 「サムネイル」「アイコン」など。 | |
| 概要 | カテゴリに含まれる成果物の種類や点数などの説明。 | |
| リンク | 各カテゴリの詳細ページへのリンクを表示する。 | |
