# P006-01: 🎮 ゲーム一覧 (/works/games/)

## 基本情報
- 主目的: 開発したゲーム作品の一覧を展示し、各ゲームの特徴と価値を伝える。
- 想定ユーザー: ポートフォリオ閲覧者、採用担当者、ゲーム開発に興味のあるユーザー。
- 想定導線: トップページ・作品一覧から遷移し、必要に応じて個別ゲームの詳細ページへ移動する。

## 表示内容

| 要素名      | 詳細                                    | 備考                                               |
|----------|---------------------------------------|--------------------------------------------------|
| 目次       | ページ内リンクで「ゲーム一覧」「カテゴリ絞り込み」へ移動できる目次を配置。 | セクション見出しとアンカーを一致させる。モバイルでは先頭固定ではなく通常配置として可読性を優先。 |
| カテゴリ絞り込み | 「すべて」「2D」「3D」「ウェブ」「その他」のカテゴリで絞り込み可能 | 存在しないカテゴリは表示しない |
| ゲーム一覧    | 公開済みゲームの詳細ページへ飛ぶカードを表示。                | 公開済み（`is_published = 1`）のゲームのみ表示。 |

### ゲームカード表示について

| 要素名    | 詳細                          | 備考                                      |
|--------|------------------------------|----------------------------------------|
| サムネイル | ゲームのサムネイル画像を表示             | P006-01-01 詳細と同一画像。`alt` はゲーム名 |
| ゲーム名  | ゲームの名称を表示                | H2見出しレベルで表示             |
| カテゴリ  | ゲームのカテゴリ（2D、3D など）を表示   |                                        |
| 説明     | ゲームの概要を簡潔に記載            | 目安100〜200文字                         |
| 制作年月  | ゲーム制作の年月を表示              | `created_at` を `YYYY年M月` 形式で表示  |
| 使用技術  | ゲーム開発に使用した主要技術タグを表示   | 複数表示可能（例: Unity, C#, WebGL など） |
| リンク   | ゲームの詳細ページへのリンクを表示     | `/works/games/{game-id}/` へ遷移        |

## 備考
- 子ページ: 個別ゲームの詳細要件は P006-01-01 を参照。
- 参考: `01_DOCS/02_サイト構成/画面遷移図.md`、`01_DOCS/wiki/01_コンセプト定義/05_SEOとアクセシビリティ方針.md`
- 表記ルール: 技術名は正式名称で統一し、省略語を使う場合は初出で正式名称を併記する。
- 更新運用: ページ要件更新時は関連する`02_OUTPUT`の最新スクリーンショットとの差分確認を行い、不整合があれば先に要件を修正する。
