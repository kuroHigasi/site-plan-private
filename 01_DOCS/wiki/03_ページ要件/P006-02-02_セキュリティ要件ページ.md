# P006-02-02: セキュリティ要件 (/works/portfolio/security-requirements/)

## 基本情報
- 主目的: 本サイトのセキュリティ要件を紹介する。
- 想定ユーザー: 採用担当者、協業相手、ポートフォリオ閲覧者、技術選定の参考として閲覧する開発者。
- 想定導線: 本サイトページ。

## 表示内容

| 要素名       | 詳細                                                                                      | 備考                                                                                             |
|--------------|-------------------------------------------------------------------------------------------|--------------------------------------------------------------------------------------------------|
| 目次         | ページ内リンクで「ログイン」「管理画面」「管理API」へ移動できる目次を配置。               | セクション見出しとアンカーを一致させる。モバイルでは先頭固定ではなく通常配置として可読性を優先。 |
| 管理について | 公開を前提とした要件と、非公開の要件に分けて管理する旨を簡潔に記載。                      |                                                                                                  |
| ログイン     | 本サイトのログイン要件（認証方式、パスワードポリシー、二段階認証等）を簡潔に記載。        |                                                                                                  |
| 管理画面     | 本サイトの管理画面のセキュリティ要件（アクセス制御、権限管理、ログ管理等）を簡潔に記載。  |                                                                                                  |
| 管理API      | 本サイトの管理APIのセキュリティ要件（認証方式、アクセス制御、レート制限等）を簡潔に記載。 |                                                                                                  |

## セキュリティ要件の管理について
- セキュリティ要件は、公開を前提とした要件と、非公開の要件に分けて管理する。
- 公開を前提とした要件は、当ページに記載する。
- 非公開の要件は、プライベートリポジトリにて管理し、必要に応じて関係者に共有する。
