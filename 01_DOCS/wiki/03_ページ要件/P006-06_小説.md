# P006-06: 小説 (/works/novels/)

## 基本情報
- 主目的: 執筆・作成した小説作品の一覧を展示し、各作品の概要や掲載先へのアクセスを提供する。
- 想定ユーザー: ポートフォリオ閲覧者、創作・小説作品に興味のある読者。
- 想定導線: トップページ・作品一覧から遷移し、作品の概要確認や各掲載先へのアクセスを促す。

## 表示内容

| 要素名 | 詳細 | 備考 |
|---|---|---|
| イントロダクション | 小説執筆活動の概要や執筆ジャンル、制作へのこだわりを簡潔に説明。 | |
| カテゴリ・ジャンル絞り込み | 「すべて」「短編」「長編」「ファンタジー」「SF」などのジャンル・形態で絞り込み可能。 | 該当作品が存在するジャンルのみ表示。 |
| 小説一覧 | 作成した小説作品のカード一覧を表示。 | 公開済みの作品を表示。 |

### 小説カード表示について

| 要素名 | 詳細 | 備考 |
|---|---|---|
| 表紙 / サムネイル | 小説の表紙画像やアイキャッチ画像を表示。 | `alt` は作品名 |
| タイトル | 小説の作品名を表示。 | H2見出しレベルで表示 |
| ジャンル・タグ | 作品のジャンル（SF、ファンタジーなど）やタグを表示。 | |
| あらすじ / 概要 | 作品のあらすじ・ストーリー概要を簡潔に記載。 | 目安100〜200文字程度 |
| 執筆時期 / 状態 | 執筆・公開年月やステータス（完結、連載中、短編など）を表示。 | |
| 詳細 / 閲覧リンク | 小説詳細（P006-06-01）への遷移、または掲載先（小説投稿サイト、PDF、掲載ページ等）へのリンクを表示。 | 外部サイトへ遷移する場合は別タブで開く。 |
