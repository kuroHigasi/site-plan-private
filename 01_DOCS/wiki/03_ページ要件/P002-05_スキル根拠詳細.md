# P002-05: スキル根拠詳細 (/about/skills/:slug)

## 基本情報
- 主目的: 特定スキルの習熟度に対する詳細な根拠を提示し、信頼性を高める。
- 想定ユーザー: 技術選定者、エンジニア採用担当者、具体的なスキル経験を知りたい閲覧者。
- 想定導線: フロントエンド（P002-01）等の各スキル一覧ページのスキルカードから遷移する。

## 表示内容

| 要素名 | 詳細 | 備考 |
|:---:|:---|:---|
| スキル基本情報 | スキル名称、アイコン、現在の習熟度レベルを表示する。 | P002-01 等と共通のコンポーネントを使用。 |
| 経験期間 | その技術を使用している期間（例: 3年、2021年〜）を表示する。 | |
| 根拠Markdown | APIから取得したMarkdown文字列をパースして表示する。 | |
| 関連リンク | 関連する資格（P005系）や作品（P006系）へのリンクを表示する。 | |
| 一覧へ戻る | 元のスキルカテゴリ一覧（P002-01 等）へ戻るリンクを表示する。 | ブラウザバックまたは明示的なリンク。 |

## 動的ルーティング・データ取得仕様

### スキルスラッグによるルーティング
- パス: `/about/skills/:slug`
- `:slug` はスキルのスラッグ（例: `react`, `typescript`, `nodejs`）を指定する。

### APIによるデータ取得
- 専用のAPIエンドポイント（例: `/api/public/skills.php?slug={slug}`）からデータを取得する。
- APIは以下の情報を含むJSONを返却する想定：
    - `slug`: スキルスラッグ
    - `name`: スキル名称
    - `level`: 習熟度
    - `experiencePeriod`: 経験期間
    - `content`: 根拠となるMarkdown文字列
    - `relatedLinks`: 関連リンク（資格ID、作品IDなど）の配列
- データが存在しない場合は404エラーを返し、フロントエンド側で404ページを表示するか一覧ページへリダイレクトする。

### Markdownの構成案（APIから返却される `content` 内容）
APIが管理・返却するMarkdown内には以下の情報を含めることを推奨する。
- 具体的な経験内容（業務、個人開発）
- 苦労した点と解決策
- その技術に対する自身の見解や今後の展望
