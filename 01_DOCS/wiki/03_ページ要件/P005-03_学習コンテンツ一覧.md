# P005-03: 📚 学習コンテンツ一覧 (/certifications/contents/)

## 基本情報
- 主目的: 管理者が学習している学習資料やコンテンツの一覧を表示する。
- 想定ユーザー: 採用担当者、協業相手、ポートフォリオ閲覧者。
- 想定導線: 資格・学習コンテンツトップから遷移する。


## 表示内容

| 要素名          | 詳細                                        | 備考              |
|--------------|-------------------------------------------|-----------------|
| カテゴリ絞り込み     | カテゴリで絞り込み可能（表示するカテゴリは動的に決定） | 存在しないカテゴリは表示しない |
| コンテンツ一覧      | 学習コンテンツをカード表示して一覧とする             |                 |

### コンテンツカード表示について
| 要素名    | 詳細                       | 備考                     |
|--------|--------------------------|------------------------|
| アイコン   | カテゴリを示すアイコンを表示           |                        |
| サムネイル  | コンテンツのサムネイル画像を表示        | `alt` はコンテンツ名；`loading="lazy"` を付与 |
| コンテンツ名 | コンテンツのタイトルを表示             |                        |
| テーマ    | コンテンツのテーマ・主題を表示          |                        |
| 説明     | コンテンツの簡潔な説明文を表示          | 任意項目（存在する場合のみ表示） |
| リンク    | コンテンツ詳細ページ（P005-03-01）へのリンク | クリックで詳細ページへ遷移 |

## ルーティング・実装方式

本ページは管理画面からコンテンツを追加した際に再ビルド不要で公開できるよう、**静的 HTML + API 取得**で構成する。

| 項目 | 方針 |
|------|------|
| URL 形式 | `/certifications/contents/`（固定 URL） |
| ページ生成 | `certifications/contents/index.astro` を 1 ファイルだけ静的生成する |
| データ取得 | ブラウザで `GET /api/public/learning-contents.php` を呼び出してコンテンツ一覧を取得し描画する |
| コンテンツ追加運用 | 管理画面でコンテンツを公開すれば、再ビルド・再デプロイなしで一覧に追加される |

## 識別情報（管理画面連携）

| 項目 | 詳細 | 備考 |
|------|------|------|
| id | コンテンツ一意識別子（例: `1`, `2`） | 詳細ページの URL に使用 |
| slug | URL 用識別子（例: `python-basics`） | パスベース URL で使用（`/certifications/contents/python-basics/`） |
| title | コンテンツのタイトル | 一覧・詳細で共通 |
| theme | テーマ・主題（例: プログラミング、デザイン、言語等） | カテゴリ絞り込みに使用 |
| thumbnail_url | コンテンツのサムネイル画像 URL | カード表示に使用 |
| description | コンテンツの簡潔な説明文 | カード表示に使用（任意項目） |
| is_published | 公開 / 下書き | 下書き時は一覧に非表示 |

## SEO・アクセシビリティ

- パンくず: `共通仕様.md` 2.4 の P005-03 定義に準拠する（`トップ / 資格・学習コンテンツ / 学習コンテンツ`）。
- アクセシビリティ: カテゴリ絞り込みに `aria-label` を付与し、スクリーンリーダー対応を確保する。
- サムネイル: `<img>` に `alt` を必須とし、`loading="lazy"` を付与する。
