# P006-06-01: 📖 小説詳細 (/works/novels/detail?slug=sample-novel-1)

## 基本情報
- 主目的: 特定の小説作品のあらすじ、登場人物、世界観設定、執筆情報などの詳細を提供し、エピソード一覧から各話の閲覧へ導く。
- 想定ユーザー: ポートフォリオ閲覧者、創作・小説作品に興味のある読者。
- 想定導線:
  - 主: P006-06（小説一覧）の小説カードから遷移する。
  - 副: SNSや外部サイトからの直接リンク。

## ルーティング・実装方式

本ページは他の詳細ページ（YouTube動画詳細やブログ記事等）と同様に、管理画面から作品を追加した際に再ビルド不要で公開できるよう、**単一の静的ページ + クライアントサイド取得**で構成する。

| 項目 | 方針 |
|------|------|
| URL 形式 | `/works/novels/detail?slug={slug}`（クエリパラメータで作品を指定） |
| ページ生成 | `works/novels/detail.astro` を 1 ファイルだけ静的生成する。`slug` 別の `getStaticPaths` は使用しない |
| データ取得 | ブラウザで `slug` を `URLSearchParams` から取得し、`GET /api/public/novels.php?slug={slug}` を呼び出して描画する |
| 作品追加運用 | 管理画面で作品を公開すれば、再ビルド・再デプロイなしで詳細ページが閲覧可能になる |
| slug 不正・未指定 | API の `slug` 制約（`^[a-z0-9]+(?:-[a-z0-9]+)*$`）に準拠して検証し、不正・未指定時はエラー表示 + 一覧へ戻る導線を出す |
| slug 不存在・非公開 | API が `404` を返すため「作品が見つかりません」を表示し、一覧へ戻る導線を出す |

## 識別情報（管理画面連携）

| 項目 | 詳細 | 備考 |
|------|------|------|
| slug | URL 用識別子（例: `sample-novel-1`） | 英小文字・数字・ハイフンのみ。一覧・詳細で共通 |
| title | 小説タイトル | 一覧・詳細・パンくずで共通 |
| genre | ジャンル（SF, ファンタジー, 現代, ミステリー等） | 絞り込みやバッジ表示に使用 |
| status | 連載状態（完結, 連載中, 短編等） | ステータス表示に使用 |
| published_at | 初回公開日 | `YYYY年M月D日` 形式等で表示 |
| is_published | 公開 / 下書き | 下書き時は一覧・詳細とも非表示 |

## 表示内容

| 要素名 | 詳細 | 備考 |
|--------|------|------|
| タイトル | ページ見出し（H1）として表示 | パンくず・OGP タイトルに使用。P006-06 一覧のタイトルと同一 |
| 表紙 / アイキャッチ | 小説の表紙画像を表示 | `alt` は作品名 |
| ジャンル・タグ | 作品ジャンルや関連タグをバッジ表示 | |
| ステータス・執筆情報 | 連載状態（完結 / 連載中等）、公開日・更新日、文字数目安等を表示 | |
| あらすじ | 作品のあらすじ・ストーリー紹介を表示 | |
| 作品設定・登場人物紹介 | 世界観設定や主な登場人物のプロフィール（任意項目） | 登録されている場合のみ表示 |
| エピソード一覧 / 本文への導線 | **長編**: 各話（エピソード）のリストを表示（クリックで P006-06-01-01 へ遷移）<br>**短編**: 「本文を読む」ボタンまたは直接本文リンクを表示（`episode` パラメータなしで P006-06-01-01 へ遷移） | 作品の形態（短編/長編）に応じて切り替え |
| 外部リンク・掲載先 | 小説投稿サイトや書籍化・外部掲載リンク | 存在する場合のみ表示（別タブ遷移） |
| 一覧へ戻る | P006-06 へのリンクを表示 | `画面遷移図.md` 備考に準拠 |

### エピソード一覧表示について（長編小説の場合）

| 要素名 | 詳細 | 備考 |
|--------|------|------|
| 話数 / タイトル | 各エピソードの第何話・タイトルを表示 | リンククリックで P006-06-01-01（`?slug={slug}&episode={n}`）へ遷移 |
| 公開日 / 更新日 | エピソードの公開日を表示 | `YYYY/MM/DD` 形式等 |
| 文字数目安 | 各話の文字数・読了目安時間を表示 | 例: `約3,000字（読了目安 5分）` |
| 件数 | 1 件以上 | 昇順/降順の並び替え、または目次形式で表示 |

## クライアントサイド処理フロー

```text
[ユーザー] -> (ページ閲覧)
  └─> [Astro(静的HTML)] 描画完了（Loading 状態を表示）
        └─> [クライアントJS] 発火
              ├─> 1. URLSearchParams から slug を取得・検証
              ├─> 2. GET /api/public/novels.php?slug={slug} へリクエスト送信
              ├─> 3. レスポンス（JSON）から小説データ・エピソード一覧を抽出
              ├─> 4. document.title, OGP メタ情報を更新
              └─> 5. 対象 DOM 要素に小説詳細およびエピソードリストを描画（Success 状態）
```

## SEO・アクセシビリティ

- OGP: 小説タイトル・あらすじ抜粋・表紙画像を設定する（`05_SEOとアクセシビリティ方針.md` 参照）。クエリパラメータ構成のため、API レスポンス取得後にクライアントで `document.title` と `og:*` メタを更新する。
- canonical: `?slug=` 付きの自ページ URL を canonical とする。
- サムネイル / 表紙: `<img>` に `alt` を必須とし、`loading="lazy"` を付与する。
- パンくず: `共通仕様.md` 2.4 の P006-06-01 定義に準拠する（`トップ / 作品一覧 / 小説 / [作品名]`）。
