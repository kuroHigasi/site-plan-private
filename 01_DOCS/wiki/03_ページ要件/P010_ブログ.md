# P010: ブログ (/blog/)

## 基本情報
- 主目的: ブログ記事の一覧と詳細を提供し、情報発信やポートフォリオの補完を行う。
- 想定ユーザー: ポートフォリオ閲覧者、採用担当者、情報収集を行うユーザー。
- 想定導線: トップページ・作品一覧から遷移する。

## 表示内容

| 要素名      | 詳細                                            | 備考                                               |
|----------|-----------------------------------------------|--------------------------------------------------|
| カテゴリ絞り込み | 「フロントエンド」「バックエンド」「デザイン」「その他」などのカテゴリを絞り込み表示する。 | P002 プロフィールで表示するカテゴリと等しい。                        |
| スキル絞り込み  | 「HTML」「CSS」「JavaScript」などのスキルを絞り込み表示する。       | P002_01, P002_02, P002_03, P002_04 で表示するスキルと等しい。 |
| ソート      | 「新しい順」「古い順」「人気順」などで記事をソートする。                  | デフォルトは「新しい順」。                                    |
| 記事一覧     | 記事カードを一覧表示する。                                 |                                                  |

### カテゴリカード表示について
| 要素名     | 詳細                         | 備考 |
|---------|----------------------------|----|
| タイトル    | ブログのタイトルを表示。               |    |
| サムネイル画像 | ブログのサムネイル画像を表示。            |    |
| カテゴリ名   | 「フロントエンド」「バックエンド」など。       |    |
| スキル名    | 「HTML」「CSS」「JavaScript」など。 |    |
| 概要      | カテゴリに含まれる成果物の種類や点数などの説明。   |    |
