# P009-02: アイコン (/works/design/icons/)

## 基本情報
- 主目的: アプリケーション、ウェブサイト、または個人用に作成したアイコン作品を展示する。
- 想定ユーザー: シンプルな造形や、シンボリックなデザインのスキルを確認したいユーザー。
- 想定導線: デザイン（P009）から遷移する。

## 表示内容

| 要素名 | 詳細 | 備考 |
|--------|---------------------------------------|--------------------------------------------------|
| アイコン一覧 | 制作したアイコンを一覧表示する。 | 単品またはセット形式で表示。 |
| プレビュー | 背景色（白/黒）の切り替え機能。 | アイコンの視認性を確認するため。 |

### 各アイコン表示項目
| 要素名 | 詳細 | 備考 |
|--------|------------------------------|----------------------------------------|
| 画像 | アイコン本体。 | SVG形式や高解像度画像。 |
| 名称 | アイコンの名称。 | |
| 制作年月 | 制作した年月を表示。 | |
| 使用ツール | 制作に使用したツール（例: Adobe Illustrator, Figma）。 | |
| 概要 | アイコンのコンセプトや用途。 | |
