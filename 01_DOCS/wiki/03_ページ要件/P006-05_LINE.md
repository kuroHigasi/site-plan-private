# P006-05: LINE (/works/line/)

## 基本情報
- 主目的: 本ブログ公式LINEの運用状況を紹介し、読者との接点や開発・運用の舞台裏を共有する。
- 想定ユーザー: ブログ読者、開発の様子に興味があるエンジニア、ポートフォリオ閲覧者。
- 想定導線: トップページ・作品一覧から遷移し、LINEの友だち追加を促す。

## 表示内容

| 要素名 | 詳細 | 備考 |
|---|---|---|
| LINE公式アカウント紹介 | 本ブログ用LINEアカウントの目的（更新通知、開発裏話の共有など）を説明。 | |
| 友だち追加ボタン | LINE公式の「友だち追加」ボタンまたはQRコードを表示。 | 外部サイト（LINE）へ遷移。 |
| 運用・開発の様子共有 | LINE内で配信している内容のサンプルや、運用のこだわりを記載。 | テキストおよび画像で紹介。 |
